# Démo 08 — suite pytest finale Checkout

Commande : `python -m pytest -q`

La suite utilise réellement :
- une fixture `@pytest.fixture` (équivalent pédagogique du `@BeforeEach`) ;
- des fonctions `test_...` ;
- des assertions `assert` ;
- des doubles manuels simples.

Les cinq comportements du fil rouge sont de vrais tests indépendants.
