# Decorator, Proxy et Facade : même composition, intentions différentes

**Slides :** 20–25

## Objectif pédagogique
Comparer trois patterns structurels proches : Decorator enrichit, Proxy contrôle l’accès, Facade simplifie un sous-système.

## Adaptation Python
Les trois objets utilisent la composition autour de la même abstraction `ReportService`. La structure est proche, mais l’intention de chaque pattern reste différente.

## Exécution

### Windows
```bat
run.bat
```

### Linux / macOS
```bash
./run.sh
```

Le script exécute `main.py` avec Python.
