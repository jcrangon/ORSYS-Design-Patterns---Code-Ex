# ADR-003 - Communication après confirmation

## Contexte
La confirmation utilisateur doit être immédiate, mais email et analytics peuvent être différés.

## Décision
Le paiement et la confirmation métier restent synchrones. Après succès, publier `ReservationConfirmed` sur un bus d'événements.

## Conséquences
- le use case garde une réponse immédiate ;
- les consumers doivent être idempotents ;
- l'observabilité du bus devient obligatoire ;
- la cohérence est éventuelle pour les traitements secondaires.
