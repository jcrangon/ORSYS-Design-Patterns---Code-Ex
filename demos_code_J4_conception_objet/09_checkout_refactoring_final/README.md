# Cas fil rouge : checkout refactoré par Strategy, Factory, Decorator et Observer

**Slides :** 38–45

## Objectif pédagogique
Terminer la journée sur une collaboration réaliste : remise interchangeable, gateway choisi par Factory, audit par Decorator et réactions secondaires via événements.

## Exécution

### Windows
```bat
run.bat
```

### Linux / macOS
```bash
./run.sh
```

Le script compile `Main.java` dans `out/` puis exécute la classe `Main`.
