# Cas fil rouge : checkout refactoré par Strategy, Factory, Decorator et Observer

**Slides :** 38–45

## Objectif pédagogique
Terminer la journée sur une collaboration réaliste : remise interchangeable, gateway choisi par Factory, audit par Decorator et réactions secondaires via événements.

## Adaptation Python
La démo garde les quatre patterns du code Java : Strategy pour la remise, Factory pour le moyen de paiement, Decorator pour l’audit et Observer via `EventBus`. Les assertions intégrées permettent de vérifier le scénario sans dépendance externe.

## Exécution

### Windows
```bat
run.bat
```

### Linux / macOS
```bash
./run.sh
```

Le script exécute `main.py` avec Python.
