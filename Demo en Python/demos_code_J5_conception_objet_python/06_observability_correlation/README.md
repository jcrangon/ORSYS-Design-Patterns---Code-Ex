# Observabilité : corrélation, métriques et preuve de fonctionnement

**Slides :** 26, 27

## Objectif pédagogique
Faire voir qu'un système observable produit volontairement les preuves nécessaires au diagnostic : contexte de requête, événement métier et métriques.

## Exécution

### Windows
```bat
run.bat
```

### Linux / macOS
```bash
./run.sh
```

Le script exécute directement `main.py`. Aucune dépendance externe ni accès réseau n'est nécessaire.
