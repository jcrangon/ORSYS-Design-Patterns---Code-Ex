# Decorator, Proxy et Facade : même composition, intentions différentes

**Slides :** 20–25

## Objectif pédagogique
Comparer trois patterns structurels proches : Decorator enrichit, Proxy contrôle l’accès, Facade simplifie un sous-système.

## Exécution

### Windows
```bat
run.bat
```

### Linux / macOS
```bash
./run.sh
```

Le script compile `Main.java` dans `out/` puis exécute la classe `Main`.
