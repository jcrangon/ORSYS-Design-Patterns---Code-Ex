# Cas fil rouge : architecture testable avec repository, payment adapter et event bus

**Slides :** 38–41

## Objectif pédagogique
Terminer par une collaboration réaliste qui combine les choix du J5 et réutilise DIP/TDD/GoF des jours précédents.

## Exécution

### Windows
```bat
run.bat
```

### Linux / macOS
```bash
./run.sh
```

Le script compile `Main.java` dans `out/` puis exécute `Main`. Aucune dépendance externe ni accès réseau n'est nécessaire.
