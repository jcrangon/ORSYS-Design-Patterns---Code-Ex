# Spike technique : tester une hypothèse avant une décision coûteuse

**Slides :** 30, 31, 36

## Objectif pédagogique
Faire une micro-expérience mesurée pour illustrer qu'un spike sert à réduire une incertitude, pas à produire du code de production.

## Exécution

### Windows
```bat
run.bat
```

### Linux / macOS
```bash
./run.sh
```

Le script compile `Main.java` dans `out/` puis exécute `Main`. Aucune dépendance externe ni accès réseau n'est nécessaire.
